# Saberes Esquecidos — página de vendas

Página de vendas do e-book **Saberes Esquecidos**, publicada com GitHub Pages.

- `index.html` — a página
- `img/` — fotos e imagem de compartilhamento

Para trocar o link de compra, procure por `href="#oferta"` no `index.html` e substitua pelo link do checkout.
